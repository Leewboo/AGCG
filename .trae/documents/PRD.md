# 全将战棋 - 产品需求文档

## 1. 产品概述

全将战棋是一款世界策略对弈游戏，玩家在棋盘上指挥武将进行战术对抗。游戏支持双人对战、人机对战、联机对战以及DIY武将编辑功能。核心玩法围绕5v5武将对决，通过移动、攻击、技能释放来消灭敌方单位。

## 2. 核心功能

### 2.1 游戏模式
| 模式 | 描述 |
|------|------|
| 双人对战 | 本机1P vs 2P热座对战 |
| 人机对战 | 1P vs AI智能对手 |
| 联机对战 | 与好友联网对战 |
| DIY武将 | 自建武将 + 积木技能编辑 |

### 2.2 功能模块
1. **主菜单**：游戏模式选择、设置、DIY武将入口
2. **选将布阵**：双方各选5名武将，依次布阵到棋盘
3. **对战界面**：棋盘、武将面板、行动按钮、技能释放
4. **DIY编辑器**：武将属性编辑、技能组合与范围设定

## 3. 核心流程

### 3.1 双人对战流程
```
开始游戏 → 选择模式(双人对战) → 1P选将 → 2P选将 → 布阵阶段 →
回合开始 → 当前玩家行动(移动+攻击 或 使用技能) → 回合结束 →
检查胜负 → 重复直到一方全灭 → 结算画面
```

### 3.2 武将行动流程
```
选择武将 → 显示可移动范围 → 选择移动/原地 → 如攻击：
显示攻击范围 → 选择目标 → 造成伤害 → 技能：选择技能 →
显示技能范围 → 选择目标 → 触发效果 → 回合结束
```

## 4. 用户界面设计

### 4.1 设计风格
- **主题**：东方战棋美学，水墨风格与现代扁平结合
- **主色调**：深墨色(#1a1a2e)配金色(#c9a227)点缀
- **辅助色**：米白(#f5f0e1)、暗红(#8b0000)代表敌方
- **棋盘**：深棕木纹质感(#3d2914)，格子有明显边界
- **字体**：思源宋体(标题) + 思源黑体(正文)

### 4.2 页面结构
| 页面 | 模块 | UI元素 |
|------|------|--------|
| 主菜单 | 标题区、模式选择、DIY入口 | 毛笔字标题、卡片式按钮、悬浮动效 |
| 选将界面 | 我方武将栏、敌方虚影、已选展示 | 武将卡牌翻转动画、能力雷达图 |
| 对战棋盘 | 8x8棋盘、回合指示、状态面板 | 格子光效选中、移动范围高亮 |
| 技能释放 | 技能按钮、范围指示、能量条 | 范围形状预览、连携特效 |
| DIY编辑器 | 属性面板、技能积木、预览区 | 拖拽式编辑、实时数值显示 |

### 4.3 范围指示设计
- **+n 十字形**：红色虚线框
- **xn 斜角形**：蓝色虚线框
- **rn 圆形**：绿色圆形扩散

### 4.4 响应式设计
- 桌面端优先，棋盘自适应缩放
- 移动端简化操作，触摸友好

## 5. 游戏规则详细说明

### 5.1 武将属性
- **生命值(HP)**：初始100，被击归零阵亡
- **攻击力(ATK)**：影响普攻伤害
- **防御力(DEF)**：减伤系数
- **移动力(MOV)**：每回合可移动格数
- **技能能量(SP)**：使用技能消耗，回合结束回复

### 5.2 战斗公式
`实际伤害 = (攻击方ATK - 防御方DEF/2) × 技能倍率`

### 5.3 地形效果
| 地形 | 加成 |
|------|------|
| 草地 | 无 |
| 山地 | 防御+20% |
| 河流 | 移动-1 |
| 城池 | ATK+10% |

## 6. 武将库

### 6.1 初始武将(示例)
| 武将名 | HP | ATK | DEF | MOV | SP | 普攻范围 | 技能 |
|--------|-----|-----|-----|-----|-----|----------|------|
| 关羽 | 120 | 25 | 15 | 3 | 100 | r1 | 青龙斩(r2) |
| 曹操 | 100 | 20 | 12 | 4 | 100 | r1 | 冰雷阵(+2) |
| 赵云 | 90 | 22 | 10 | 5 | 100 | r1 | 七探枪(x2) |
| 貂蝉 | 80 | 15 | 8 | 4 | 100 | +1 | 倾国(x1) |
| 吕布 | 130 | 30 | 20 | 3 | 100 | r1 | 无双乱舞(r3) |

### 6.2 技能类型
- **攻击技**：对范围敌人造成伤害
- **辅助技**：治疗/增益己方
- **控制技**：禁足/沉默/冰冻

## 7. AI对战逻辑

### 7.1 AI难度
- **简单**：随机行动
- **普通**：优先攻击低血量目标
- **困难**：计算最优走法，技能释放时机优化

### 7.2 AI决策树
```
1. 检查是否有击杀机会 → 优先击杀
2. 检查是否需要防守 → 移动到安全位置
3. 评估技能价值 → 选择最优技能/普攻
4. 移动到最佳攻击位置
```
