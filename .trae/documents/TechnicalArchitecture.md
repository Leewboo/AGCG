## 2. 技术选型

- **前端**：纯HTML5 + CSS3 + Vanilla JavaScript (ES6+)
- **渲染**：Canvas 2D API
- **存储**：LocalStorage (DIY武将存档)
- **网络**：WebSocket (联机对战，可扩展)

## 4. 路由定义

单页面应用，通过状态切换显示不同界面：

| 视图状态 | 描述 |
|----------|------|
| MENU | 主菜单 |
| SELECT_P1 | 1P选将阶段 |
| SELECT_P2 | 2P选将阶段 |
| DEPLOY | 布阵阶段 |
| BATTLE | 对战中 |
| GAME_OVER | 结算画面 |

## 6. 核心系统

### 6.1 移动系统
- 基于A*或简单曼哈顿距离计算可移动范围
- 考虑地形移动成本
- 移动后更新位置，清除原位置

### 6.2 战斗系统
- 普攻：目标为相邻格(r1)，伤害=ATK-DEF/2
- 技能：根据范围类型计算命中目标，应用伤害/效果

### 6.3 技能范围计算
```
+r 十字形：以目标为中心，上下左右n格
xr 斜角形：以目标为中心，对角线方向n格
rr 圆形：以目标为中心，n格半径内所有格子
```

### 6.4 AI系统
```javascript
// 简单AI决策
function aiTurn() {
  1. 获取所有己方存活武将
  2. 对每个武将：
     a. 寻找可击杀目标 → 击杀
     b. 寻找最低血量目标 → 攻击
     c. 否则向敌人移动
  3. 使用技能（如果可用且有价值）
}
```
