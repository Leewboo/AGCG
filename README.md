# 全将战棋

一款极简主义风格的回合制战棋游戏，基于纯JavaScript实现。

## 项目结构

```
/workspace/
├── index.html          # 主入口文件
├── css/
│   └── style.css     # 样式文件
├── js/
│   ├── config.js     # 配置文件（武将、技能、地形等）
│   ├── range.js      # 范围系统
│   ├── effect.js     # 效果系统
│   └── game.js       # 游戏主逻辑
└── README.md
```

## 游戏特性

### 🎮 游戏玩法

1. **武将选择阶段**：双方各选择5个武将
2. **布阵阶段**：双方依次放置武将到己方区域
3. **战斗阶段**：回合制战斗

### ⚔️ 范围系统

- **+n**：十字方向（上下左右）
- **xn**：斜角方向（对角线）
- **rn**：圆形范围（曼哈顿距离）
- 支持混合范围类型

### 🎯 技能系统

- **主动技能**：消耗能量释放
- **被动技能**：特定条件自动触发
- **召唤技能**：召唤士兵
- **特殊技能**：战吼等

### 🏔️ 地形系统

- 草地：正常移动
- 森林：防御+10%
- 山地：防御+20%
- 水域：不可通过
- 城池：防御+30%
- 沼泽：防御-10%

### 📱 响应式设计

- 完美支持手机端
- 极简主义风格UI
- 触摸友好的操作

## 文件说明

### config.js

包含所有游戏配置：
- 武将数据
- 技能定义
- 地形配置
- 游戏常量

### range.js

范围计算系统：
- 十字范围计算
- 斜角范围计算
- 圆形范围计算

### effect.js

游戏效果系统：
- 伤害计算
- 治疗效果
- 增益效果
- 召唤效果

### game.js

主游戏逻辑：
- 游戏状态管理
- 玩家交互处理
- 渲染系统
- 胜负判定

## 使用方法

1. 直接在浏览器中打开 `index.html`
2. 或者启动本地服务器：`python3 -m http.server 8000
3. 访问 http://localhost:8000

## 游戏操作

### 选择阶段

- 点击武将卡片选择
- 选择5个武将后点击确认

### 布阵阶段

- 点击上方按钮选择要放置的武将
- 点击蓝色区域放置武将

### 战斗阶段

- 点击己方武将选中
- 绿色区域：可移动范围
- 红色区域：可攻击范围
- 点击技能按钮选择技能
- 点击黄色区域释放技能
- 点击结束回合
